Zalo Bot Nhắc Lịch Google Sheet

Kiến trúc tự động hóa thông báo lịch làm việc qua Zalo OA kết hợp Google Apps Script

Hệ thống sẵn sàng triển khai

🔄 Luồng Vận Hành (Archify Flow)

1

Nhập liệu Google Sheet

Nhân sự nhập lịch công tác, thời gian, nội dung và số điện thoại/Zalo ID nhận thông báo vào Sheet.

2

Trigger Apps Script định kỳ

Hàm Time-driven Trigger chạy mỗi giờ/ngày để quét các lịch sắp diễn ra cần nhắc nhở.

3

Gọi Zalo OA API

Apps Script đóng gói dữ liệu và gửi yêu cầu POST đến openapi.zalo.me/v2.0/oa/message.

4

Gửi tin nhắn cho nhân viên

Nhân viên nhận được tin nhắn ZNS hoặc tin nhắn chat trực tiếp từ Zalo Official Account của công ty.

💻 Mã nguồn Apps Script Mẫu

Đoạn code cốt lõi xử lý việc quét Google Sheet và gọi API Zalo:

function sendZaloReminders() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet()
                            .getSheetByName("Lich");
  var rows = sheet.getDataRange().getValues();

  // Lấy Access Token của Zalo OA
  var token = "ZALO_OA_ACCESS_TOKEN_HERE";

  for (var i = 1; i < rows.length; i++) {
    var row = rows[i];
    var trangThai = row[3]; // Cột trạng thái

    if (trangThai == "Chưa gửi") {
      var zaloId = row[1];
      var noiDung = row[2];

      var payload = {
        "recipient": { "user_id": zaloId },
        "message": { "text": "🔔 Nhắc lịch: " + noiDung }
      };

      var options = {
        "method": "post",
        "contentType": "application/json",
        "headers": { "access_token": token },
        "payload": JSON.stringify(payload)
      };

      UrlFetchApp.fetch(
        "https://openapi.zalo.me/v2.0/oa/message",
        options
      );

      sheet.getRange(i + 1, 4).setValue("Đã gửi");
    }
  }
}

⚙️ Hướng dẫn cài đặt nhanh

Bước 1: Tạo Zalo OA

Đăng ký tài khoản Zalo Official Account, xác thực doanh nghiệp và lấy Access Token.

Bước 2: Thiết lập Google Sheet

Tạo các cột: Tên nhân viên, Zalo User ID, Nội dung lịch, Trạng thái.

Bước 3: Cài đặt Trigger

Vào Extensions > Apps Script, dán code mẫu và thiết lập hẹn giờ chạy tự động (Time-driven).
